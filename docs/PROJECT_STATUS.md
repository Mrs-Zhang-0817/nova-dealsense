# 项目交接与当前状态

更新于 2026-11-17。本文是新队友的入口；功能细节以源码、测试和所链接的文档为准。

## 我们要做什么

NOVA DealSense 面向中国中小制造出口商，帮助团队从订单报价与成本出发，计算贡献利润，在利润、产能、交期等约束下反推可行报价，比较方案并保存决策依据。当前演示场景是中国出口美国的单商品订单。长期方向是把邮件或 RFQ 文件变成可追溯的询盘草稿，经过人工审批后建单、研究市场信息、生成报价并再次审批发送。产品范围见 [PRD](PRD.md)，V2 设计见 [架构方案](V2_ARCHITECTURE_PLAN.md)。

## 尚未完成

邮箱和文件接入、解析与抽取、身份和租户授权、企业及市场证据、建单审批、报价审批与发送都未实现。现有 `POST /deals` 与报告下载缺少真实用户授权，不能直接作为多租户生产服务使用。示例数据和本机演示结果不能视为真实政策、汇率或客户资料。

## 新队友从哪里开始

1. 阅读本页、[PRD](PRD.md) 和 [V2 基线审计](V2_AUDIT_REPORT.md)，区分已实现的 V1.1 与拟建的 V2。
2. 按根目录 [README](../README.md) 启动本地环境，使用 `sample_data/` 的合成案例。不要提交 `.env`、数据库、备份或生成报告。
3. 读 [架构](ARCHITECTURE.md)、[数据库](DATABASE.md) 和 [API 映射](PHASE1_API_MAPPING.md)；改接口时同步更新契约与测试。
4. 从 [实施顺序](PHASE1_IMPLEMENTATION_PLAN.md) 领取小任务。涉及真实数据、建单或发送的功能先明确身份、审批版本和可追溯证据。
