# NOVA DealSense V1.1 技术要点
1. 每笔订单独立指定起运地、目的地、报告币种与贸易术语。市场及启用状态由数据库提供。
2. Python Decimal 以原币数量和金额计算，按快照汇率折算；逐行四舍五入至 8 位。汇率记录方向、来源、日期。估算与确认状态分开。
3. 单价下限等于纳入成本除以数量与 (1 − 目标贡献率) 的乘积。在议价网格上向上取整，再验证实际利润率和硬约束。
4. 枚举报价、数量与物流选项；产能、报价上限、总预算、起订量、最低利润和交期逐项校验。最多评估 1000 个候选，保存截断标记。
5. 利润优先最大化贡献利润。买家匹配最小化客户价格、数量和交期的平均相对偏差。低风险使用产能及交期占用率代理，并记录确定性平局规则。
6. 区分可行、不可行和依据不足。缺少生产、交付或数量变化成本依据时提示补充，截断且未找到可行解时不推断整个网格无解。
7. PostgreSQL 保存订单、市场、汇率、参数、版本及逐项检查，可复算历史运行。
8. 决策选择追加保存；报告冻结选择、备选、依据和 PDF 字节，后续改价后仍可下载原报告。
9. 汇率与运力等演示输入显式标记，前端财务值来自后端；首页按真实业务、演示、未标注来源分别统计。
10. 当前覆盖单商品优化。定额成本与随数量变化的成本需要人工确认。产能代理指标不提供违约概率；税费与运输条件需业务核验。本机演示采用确定性计算，无需外部 AI、关税或买家数据服务。
