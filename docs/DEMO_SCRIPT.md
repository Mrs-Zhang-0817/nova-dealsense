# 现场演示 · 约 6 分钟
|时间|点击与转场|讲解及预期|
|---|---|---|
|0:00–0:40|打开首页，决策总览切到「演示数据」|介绍制造出口商如何在利润、客户限价和交付约束间定价。看板从 PostgreSQL 读取；订单总额按报告币种分别汇总。|
|0:40–1:30|订单管理 → 搜索「提交演示 A」→ 打开详情 → 订单分析|5000 件 × USD 3.00；单位成本 CNY 12.96 ÷ 7.20 = USD 1.80。含 USD 2500 固定成本后总成本 USD 11500，贡献率 23.33%，低于 25%。|
|1:30–3:00|反向优化 → 选择买家匹配 → 填写下述参数 → 运行优化|价格范围 3.00 到 3.09，步长 0.01；数量上下限均为 5000，步长 1；目标 0.25，最低利润 0。总产能 5000、交期 10 天、准备 1 天、日产 1000、演示物流 4 天，替换运费留空。以上为人工演示假设。|
|3:00–4:00|比较已保存方案 → 切换三个策略的历史运行|3.07、3.08、3.09 均可行。利润优先选 3.09；低风险的占用率和交期相同，以利润打破平局；买家匹配选 3.07。容量利用率 100%，交付余量 0 天。|
|4:00–5:00|选买家匹配的 3.07，填决策人及说明，保存选择 → 生成决策报告|销售收入 USD 15350、贡献利润 USD 3850、贡献率 25.08%。与 3.09 相比让出 USD 100 预计贡献利润，更接近原报价。|
|5:00–6:00|下载 PDF，在 Edge 打开；回首页看近期报告|展示八节报告、人工汇率、产能与未核验税费。解释确定性枚举、约束验证、历史快照。|
若现场来不及填参数，从 A 订单「历史优化」或「方案对比」读取预存的三次运行。订单 B 限价 USD 3.00，可展示不可行；订单 C 缺准备天数，可展示依据不足。三项均是合成案例。接口异常先运行 verify.ps1 核对后端及数据库；页面异常确认 API 地址和端口。服务无法恢复时打开提交包 demo_data/bottle-report.pdf 和 screenshots 中的现场截图，说明为事先保存的演示结果。
