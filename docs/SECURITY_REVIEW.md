# 提交范围安全检查
本版用于本机演示。提交启动脚本将 API 和生产前端绑定回环地址；FastAPI 跨域来源取自 FRONTEND_ORIGIN。CORS 不提供身份验证。若要公网或多租户使用，需另行实施身份验证、订单级授权和 TLS；不要将本地服务直接暴露到公网。
- 配置：根 .env 只在本机使用；样例中密码是开发占位。唯一公开给客户端的项目配置是 NEXT_PUBLIC_API_BASE_URL。AI 接口和文件上传未启用。
- 访问：PDF 下载接收 UUID，按报告行取数据库字节，不接受本地路径。备份与 PDF 字体路径仅由本机维护者通过 CLI 或环境指定。报告含买家数据，真实报告和备份不进入提交包。
- 日志：生产脚本使用 --no-access-log；SQLAlchemy hide_parameters 启用。通用异常记录异常类型，不写请求正文、联系人或 SQL 参数。
- 发布物：按目录与文件类型白名单复制应用源文件。归档复核禁止环境文件（.env.example 除外）、依赖目录、临时库、缓存、日志及个人文件。仅导出演示库合成数据的截图与样例 PDF。
- 依赖：本次 npm audit 和针对 Windows 精确锁定版本的 pip-audit 均未报告已知漏洞。审计是当前版本的公告检查，不能替代访问控制或渗透测试。
- 本目录没有 Git 元数据，不能核验外部仓库提交历史或创建提交标签。源码备份与提交 ZIP 分别保存。
